→ Privacy; they can be turned off again without losing functionality. The
canonical Privacy Notice at https://prompttopage.xyz/privacy describes the
complete payload and recipient. A separate update check contacts GitHub after
launch by default and can be turned off in Settings → Updates. Downloading a model
on first run requires an internet connection and is subject to the model provider's
terms.
